# OOC Chat

SillyTavern의 별도 OOC 입력창입니다. 현재 버전은 **1.6.2**입니다.

## 설치와 전송

확장 설치 메뉴에서 `https://github.com/bongbong11/OOC_CHAT`를 설치하세요.

- OOC 입력창에 내용을 적고 전송 버튼이나 Enter를 누릅니다. Shift+Enter는 줄바꿈입니다.
- 영문 입력은 바로 전송됩니다.
- 기본은 원문 전송입니다. 번역 기능 없이 한글·영문을 기존처럼 보낼 수 있습니다.
- 확장 설정 → **OOC Chat → 번역 확장 연동**을 체크하면 한글 입력을 영어로 번역한 뒤 전송합니다. 채팅 화면·저장 메시지·모델 요청에 같은 번역 내용이 사용됩니다.
- 연동을 켠 경우에는 한국어→영어 입력 번역 기능과 번역용 Connection Profile 설정이 필요합니다. 번역 요청은 선택한 외부 API와 모델을 사용합니다.
- 연동이 켜져 있을 때 번역 기능 없음·번역 실패·빈 결과·시간 초과·입력 또는 채팅 변경 시 전송을 중단하고 미전송 원문을 유지합니다. 원문으로 보내려면 연동 체크를 끄고 다시 전송하세요.
- 체크를 번역 도중 끄면 진행 중 요청을 취소하고 원문을 유지합니다. 설정은 즉시 저장됩니다.
- 전송 중 버튼과 입력창은 잠깁니다. 영어로 직접 입력하면 번역 모델은 호출하지 않습니다.

## OOC 설정

입력창 왼쪽 **OOC** 버튼을 누릅니다.

- **프롬프트 제외**: 현재 생성 프리셋에서 OOC 생성 때만 제외할 프롬프트를 체크합니다. 선택은 프리셋별로 저장되고 일반 생성에는 적용되지 않습니다. **전체 해제**는 현재 프리셋의 체크만 지웁니다.
- **OOC 프롬프트**: 이름별 목록에서 선택하면 즉시 적용됩니다. **추가**로 새 이름과 내용을 작성하고 **저장**하세요. 선택한 항목의 이름·내용을 편집하고 저장할 수도 있습니다. **삭제**는 선택한 항목만 지우며, **사용 안 함**은 저장 목록을 유지하고 추가 주입을 끕니다.
- 수정 내용은 저장 버튼을 눌러야 남습니다. 다른 항목을 선택하거나 창을 닫기 전에 저장하세요. 빈 내용으로 저장한 항목은 추가 프롬프트를 주입하지 않습니다.
- 선택한 인격 프롬프트는 해당 OOC 생성의 최신 사용자 입력에 기존 `<OOC_INSTRUCTION>` 형식으로 결합됩니다. 채팅 저장 본문에는 인격 프롬프트가 들어가지 않습니다.

확장 설정 패널에서는 입력창 표시, 번역 확장 연동, OOC 뒤 고정 문구, 메시지 색상을 설정할 수 있습니다. 입력창 아래 화살표는 접기·펼치기입니다.

## 저장과 기존 데이터

- 설정과 프리셋별 제외 목록: SillyTavern 확장 설정 `OOC_CHAT`.
- **번역 확장 연동** 기본값은 꺼짐입니다. 이전 버전에서 자동 번역을 사용했다면 업데이트 후 체크를 한 번 켜 주세요. 이후 선택은 저장됩니다.
- 이름별 인격 목록과 선택: 계정 저장소 `OOC_CHAT_PERSONA_PRESETS`.
- 이전 단일 인격 프롬프트는 처음 읽을 때 **기존 OOC 프롬프트**로 이관되고 자동 선택됩니다. 기존 저장 키는 보존됩니다. 새 목록에서 삭제한 항목은 다시 생기지 않습니다.
- OOC 메시지는 해당 채팅에 기존 `extra.ooc_chat` 표시와 함께 저장되어 다시 열 때 복원됩니다.
- 목록 데이터가 손상되거나 지원하지 않는 버전이면 덮어쓰지 않고 오류를 표시합니다.

## 검증

`node --test tests/ooc.test.cjs`로 전송, 번역 연동 ON/OFF, 실패, 중복, 채팅 변경, 인격 이관·저장·삭제와 프롬프트 제외 복원을 검사합니다. 브라우저 모의 검증과 실제 환경에서 남은 확인 사항은 [검수 기록](AUDIT-1.6.2.md)을 참고하세요.
